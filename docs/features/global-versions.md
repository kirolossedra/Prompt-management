# Global Versions

## Purpose

Global Versions are explicit vault-wide baselines. They are separate from the automatic version history of individual Prompts.

## Release

The owner chooses when to release a Global Version and may provide a title and release summary.

## Snapshot scope

The current snapshot can include the workspace profile, activity, achievements, hierarchy, Prompts, Prompt histories, files, relationships, Finder feedback, Mindsets, Preferences, Decisions and legacy local-commit records.

## UI capabilities

- Release a new Global Version.
- Show record counts.
- Browse snapshot contents.
- Compare two baselines.
- Report Prompt count delta.
- Report local-version count delta.
- Identify changed Prompt states.
- Download snapshot JSON.
- Edit Global Version metadata.
- Archive/delete Global Version records.

## Evolution

Vault-level versioning existed by the 2026-08-07 version-control work. Snapshot breadth evolved with the product:

- files added to snapshots on 2026-08-08;
- Prompt relationships added on 2026-08-08;
- Finder feedback added to the snapshot model on 2026-08-18.
